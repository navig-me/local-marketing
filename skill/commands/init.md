description: Set up local-marketing for this project (interview, research, scaffolding)
---

Run the local-marketing init flow for the current project, following the
"Init interview" section of the local-marketing SKILL.md exactly: interview
the user one question at a time with a recommended default, research their
company/market with your own web tools, then run
`npx @navig-me/local-marketing init` with the collected answers to scaffold
the local data directory.
